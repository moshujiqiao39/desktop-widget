# 桌面小组件 · 天气 / 时间 / CPU / 内存

一张贴在桌面右下角的小卡片：抬眼就知道外面什么天气、机器累不累，不用开浏览器。

## 怎么用

双击 **`启动小组件.vbs`**（不会弹黑框）。

| 操作 | 效果 |
| --- | --- |
| 右上角 `—` | 最小化：收起成只显示时间/温度的小条 |
| 右上角 `顶` | 一键置顶 / 取消置顶（亮=已置顶，暗=普通层） |
| 右上角 `⚙` | 打开设置：显示哪些模块 / 是否置顶 / 背景颜色 / 不透明度 |
| 右上角 `✕` | 隐藏到托盘（进程还在，点任务栏快捷方式或托盘图标就回来） |
| 点「AI 今日」行 | 打开 AI 用量面板：各应用的已用 token / 账户余额 |
| 点「待办」行 | 打开待办列表：新建 / 编辑 / 完成 / 删除 |
| 左键拖动 | 挪位置，松手自动记住 |
| 右键 | 菜单：刷新天气 / 重新定位 / 置顶 / 调试信息 / 退出 |
| 托盘图标双击 | 隐藏 / 显示 |
| 托盘右键 | 刷新天气 / 退出 |

`顶`、设置页里的「置顶显示」开关、右键菜单里的「置顶显示」是同一个状态，改哪个另外两个都会跟着变。

## 待办

主界面卡片上有一条「待办 · 时间 事情」，点它打开待办页：

- **新建 / 编辑**：事情、时间、是否提醒、提醒时间
- 时间可以写 `11-18 18:00`、`2026-11-18 18:00`，也可以偷懒只写 `18:00`（按今天算）
- 左边的 `○` 点一下标记完成（`●`），完成的行会置灰加删除线
- 编辑界面里有「删除」

**到点提醒**：开启提醒的任务，到时间会

1. 自动把小组件**置顶**（即使你之前关掉了置顶）
2. 如果收起了/隐藏了，自动展开并显示
3. 卡片上方弹出琥珀色提醒条（时间 + 事情），并响一声系统提示音
4. 点「知道了」关掉，置顶状态回到你原来的设置

待办存在 `tasks.json`，关掉再开还在。提醒只在小组件运行时有效——电脑关机或程序退出时不会响。

## AI 用量

主界面上有一行「AI 今日 · …」，点开是明细：

自动探测本机的 AI 应用，**能读的直接读，读不到的才要你填 key**：

| 应用 | 数据来源 | 需要什么 | 刷新 |
| --- | --- | --- | --- |
| Claude Code | `~/.claude/projects/**/*.jsonl` 里的 `usage` 字段 | 无（只读本地文件） | 每 5 分钟（增量） |
| DeepSeek Harness | 解压会话日志，按**每次请求的模型 + 时段**折算人民币 | 需要本机 Node（>=22 才有 zstd） | **每 30 秒** |
| Codex | `~/.codex/state_5.sqlite` 的 `threads.tokens_used` | 需要本机装有 Python（用它的 sqlite3 读） | 每 5 分钟 |
| DeepSeek | `api.deepseek.com/user/balance` | 需要填一个 API key（存在 `config.json`，只发给你自己的余额接口） | 手动/按需 |

口径说明：

- **Claude / Codex** 显示的是**今天已用**多少 token（本地记录，不需要账号）
- **DSH** 显示**今天花了多少钱**（人民币），每 30 秒重算一次。不是拿总量乘一个价，而是**把会话日志逐帧解开，按每一次请求当时的模型和时段**分别计价再累加：

  | 单价（元 / 百万 tokens，高峰价） | 缓存命中 | 缓存未命中 | 输出 |
  | --- | --- | --- | --- |
  | `deepseek-flash` | 0.04 | 2.00 | 8.00 |
  | `deepseek-v4-pro` | 0.30 | 9.00 | 27.00 |

  **时段规则**（照官方定价页）：北京时间**周一至周五 9:00-12:00、14:00-18:00 为高峰**，其余时段（含周末）空闲，价格减半。所以晚上、周末跑同样的量，显示的钱会少一半。

  面板那行会写清楚：`650 次 · deepseek-flash · 高峰时段`；如果有跨时段的部分，会拆成 `高峰 ¥x / 空闲 ¥y`。法定节假日没有单独识别（当天会按高峰算，略微高估）。
- **DeepSeek** 显示的是**账户余额**（人民币），需要填一个 `sk-` 开头的 API key；DSH 自己的登录令牌是 `platform.deepseek.com` 的 OAuth token，换不到开放平台余额
- 订阅制的 ChatGPT Plus / Claude Pro / Cursor Pro **没有**公开的 token 余额接口，所以这几个只能看本地已用量

刷新：本地面板每 `aiRefreshMinutes`（默认 5 分钟）增量扫一次，Claude 的文件按「修改时间 + 大小」做缓存，不会每次重读 30 多 MB；面板上也有「刷新」按钮。DeepSeek 余额按需查询，不会定时打接口。

隐私：只读你本机的日志和数据库，**不上传任何内容**；API key 只存在本机 `config.json` 里。
## 最小化

点 `—` 会收起成下面这样的小条（140×44 的胶囊，只留时间和温度），贴在原来的右下角，点 `▢` 展开：

为什么不是缩到任务栏：窗口是 PowerShell 托管的，一旦进任务栏就会被 Windows 标成「Windows PowerShell」、挂个终端图标，收进去之后还要多一个名字奇怪的按钮。所以做成「原地收起」，既不占地方，也不用去任务栏里找。

小条状态下照样可以拖动、右键菜单、托盘操作；展开时会保持右下角不动，不会跳位置。

右上角的 `✕` 只是**隐藏**，不会杀进程——想彻底关掉用右键菜单 →「退出」，或者托盘右键 →「退出」。

## 设置页

点右上角 `⚙`，卡片原地翻成设置页；再点 `⚙` 或 `✕` 收起。改动**立刻生效**并写进 `config.json`。

- **显示内容** —— 天气 / 时间 / CPU / 内存，四个开关各自独立。全关掉会显示一行提示，不会变成空卡片。
- **置顶显示** —— 关掉后窗口不再压在其他窗口上面（和右键菜单里的开关同步）。
- **背景颜色（调色盘）** —— 色相条 + 饱和度/明度方块，按住拖动即可取任意颜色，旁边实时显示十六进制值。卡片会按主色生成上浅下深的渐变，阴影跟着走。
- **文字自动反色** —— 背景亮度超过阈值时，文字、图标、分隔线、进度条底色会自动切成深色；换成深色背景再自动切回浅色。不需要手动挑字色。浅色背景的效果：

- **不透明度** —— 35% ~ 100%，**只改卡片背景的透明度**，文字、图标始终满不透明（所以调得很透也依然清晰），阴影会跟着一起变淡。

- **恢复默认设置** —— 一键回到初始状态（深灰底、96% 不透明度、四个模块全开、置顶）。

对应配置字段：`showWeather` / `showTime` / `showCpu` / `showMem` / `alwaysOnTop` / `background`（任意十六进制，如 `#F2E4C9`）/ `opacity`。设置页打开时，卡片会临时往上让一点，保证整页在屏幕内；收起后底边保持原样。

## 从任务栏打开

窗口是 PowerShell 托管的（进程名 `powershell.exe`），直接放任务栏会被 Windows 叫成「Windows PowerShell」、用终端图标，很乱。所以改成给你一个**自己的快捷方式**：

1. 双击 **`创建任务栏快捷方式.bat`** → 桌面出现「桌面小组件」图标（带天气图标）；
2. 把它拖到任务栏上，或者右键 → 显示更多选项 → 固定到任务栏；
3. 以后点这个图标：**已经在跑就把窗口叫出来**（单实例 + 事件唤醒，不会开第二个），没在跑就启动它。

位置、置顶状态、透明度都记在 `config.json`，下次启动回到原位。

## 它怎么知道你在哪

两条路并行，取更准的那个：

1. **设备实时定位** —— Windows 定位服务，精度到街区。需要「设置 → 隐私和安全性 → 位置」里「定位服务」和「允许桌面应用访问你的位置」都打开；台式机/没 Wi-Fi 的机器经常拿不到。
2. **IP 定位** —— 先问 `ip-api.com`，失败再问 `ipinfo.io`，精度到城市。不需要任何权限，通常几百毫秒就回来，顺带拿到城市名和时区。

设备定位成功会覆盖 IP 结果；反过来不会覆盖回去。两条都不通时，才用 `config.json` 里手写的 `city` 去地理编码。

## 天气从哪来

两个源，自动切换：

1. **wttr.in**（主）—— 免费、无需 Key，国内可直连，实测 1 秒内返回。
2. **Open-Meteo**（备）—— wttr.in 挂了会自动切过去。

**注意**：`api.open-meteo.com` 在部分网络下连不通（我实测这台机器就是），所以它只做备用，主源是 wttr.in。右下角会标出当前用的是哪个源、几点更新的。

## 时间

- 时钟按**本机时区**走。
- 天气所在地的时区如果和本机不一样（出差、换了出口），左下角会变成「当地 14:20 · UTC+9」，提醒你那个地方现在几点。时区名会做 IANA → Windows 映射，认不出来的按经度估算。

## 配置文件 config.json

| 字段 | 说明 |
| --- | --- |
| `city` | 城市名，定位成功后自动写入 |
| `latitude` / `longitude` | 坐标，自动写入；手动填也能直接用 |
| `locatedBy` | 上次定位方式：`device` / `ip` / `config` |
| `weatherProvider` | 上次成功的天气源 |
| `showWeather` / `showTime` / `showCpu` / `showMem` / `showTasks` / `showAi` | 六个模块是否显示 |
| `deepseekKey` | DeepSeek API key（查余额用，明文存在本机） |
| `aiRefreshMinutes` | AI 用量刷新间隔，默认 5 分钟 |
| `background` | 卡片主色，任意十六进制，如 `#1B2130` / `#F2E4C9`（调色盘实时写这个） |
| `opacity` | 不透明度 0.35~1，默认 `0.96` |
| `alwaysOnTop` | 是否置顶，设置页和右键菜单里都能切 |
| `left` / `top` | 窗口坐标，拖动后自动记录 |
| `weatherRefreshMinutes` | 天气刷新间隔，默认 `10` 分钟 |

改完存盘后重开一次即可生效；设置页里的开关会立刻生效并自动保存。

## 开机自启（可选）

`Win + R` → 输入 `shell:startup` → 把 `启动小组件.vbs` 的**快捷方式**丢进去。

## 出问题怎么办

- 界面写「获取失败」：右键 → **调试信息**，会显示定位来源、坐标、时区、当前数据源和最近的错误。
- 详细日志：`logs\widget.log`，每次定位、请求、错误都有记录。
- 双击 **`诊断.bat`**：不开窗，直接把定位、天气、CPU、内存的实测结果打在命令行里。

常见原因：
- **定位一直失败** —— 系统位置权限没给，且 IP 定位被网络挡了。在 `config.json` 里手写 `"city": "杭州"` 即可。
- **天气「获取失败」** —— 先看能不能打开 `wttr.in`。公司网络/代理可能需要给 `powershell.exe` 放行。
- **窗口不见了** —— 双击托盘图标；或右键托盘「退出」后重开。
- **窗口跑到屏幕外** —— 删掉 `config.json` 里的 `left` / `top`（改成 `null`）重开，会重新贴右下角。

## 后面想加东西

加模块（日程、待办、股价、网速……）的套路：

1. 在 `Widget.ps1` 的 XAML 里加一段区块，给它 `x:Name`。
2. 把名字登记到 `New-Widget` 的 `$script:UI` 列表里。
3. 写一个 `Update-xxx`，在 `Update-Tick` 里调用（1 秒一次）。
4. 要联网就 `Start-HttpRequest -Kind 'xxx' -Url '...'`，回来在 `Handle-HttpResult` 里加分支——请求是队列化的，不用自己碰线程。
